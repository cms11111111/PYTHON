===========================================================
   GitHub 自動打包 APK 完整操作手冊 (標準流程版)
===========================================================

【最重要原則：電腦驗證優先】
在進行任何上傳或打包動作前，請務必先完成以下驗證！

-----------------------------------------------------------
【第一階段】電腦功能驗證 (核心步驟)
-----------------------------------------------------------
1. 啟動測試：
   在終端機輸入：python MyPythonProject/main.py

2. 驗證清單：
   - [ ] 介面顯示：視窗寬度適中，文字、按鈕清晰不被切斷。
   - [ ] 新增功能：能正常儲存收支，且上方概況卡片數值立即更新。
   - [ ] 查詢功能：能依照日期篩選出歷史紀錄。
   - [ ] 預算功能：能設定當月預算，且餘額計算正確。
   - [ ] 自動存檔：關閉程式後重開，之前的資料還在 (CSV 存檔成功)。
   - [ ] 備份功能：點擊備份後，同資料夾有出現備份檔。

★ 只有以上項目皆通過，才進入下方的打包流程。

-----------------------------------------------------------
【第二階段】上傳與雲端打包 (日常操作)
-----------------------------------------------------------
1. 執行上傳：
   在 VS Code 終端機貼上這行「一條龍指令」：
   git add . && git commit -m "Update app" && git push

2. 觸發機制：
   執行完 push 後，GitHub 雲端電腦會「自動」開始打包 APK。

-----------------------------------------------------------
【第三階段】下載與領取成品
-----------------------------------------------------------
1. 前往網址 (請自行替換帳號與專案名)：
   https://github.com/您的GitHub帳號/您的專案名稱/actions

2. 等待結果：
   黃色圓圈轉動中 = 打包中 (約 10-15 分鐘)。
   綠色打勾 ✅ = 成功！

3. 下載：
   點擊工作標題 -> 滑到最下方 "Artifacts" -> 點擊 "android-app" 下載。

4. 安裝：
   解壓縮 ZIP，傳送到手機點擊安裝。若有安全警告請選「仍要安裝」。

-----------------------------------------------------------
【第四階段】初次環境設定 (只需做一次)
-----------------------------------------------------------
1. 建立 ".github/workflows/build.yml" 設定檔。
2. 在 GitHub 建立新 Repository 並連結遠端位址：
   git remote add origin https://github.com/您的帳號/您的專案名.git

===========================================================
常見問題
===========================================================
- 打包失敗 ❌：通常是使用了手機不支援的套件 (如 pandas)。
- 畫面全白：通常是 Android 檔案讀寫權限或路徑錯誤。
