=========================================
   GitHub 雲端自動打包 APK 流程說明
=========================================

1. 專案相關資訊
-----------------------------------------
● GitHub 專案網址: 
  https://github.com/帳號/PYTHON

● GitHub Actions 打包進度查看:
  https://github.com/帳號/PYTHON/actions

2. 如何觸發打包 (在 VS Code 終端機執行)
-----------------------------------------
當您修改完程式碼 (main.py) 並在電腦上驗證無誤後，請複製並貼上以下「一條龍指令」：

指令：
git add . && git commit -m "update" && git push

指令解析：
- git add . : 準備所有修改過的檔案。
- git commit -m "update" : 存檔並註解。
- git push : 上傳到 GitHub 並啟動雲端打包。

3. 打包流程與下載步驟
-----------------------------------------
1. 執行完上述指令後，開啟 GitHub Actions 網頁。
2. 您會看到最上面有一個名為 "Build Android APK" 的工作正在跑 (黃色圓圈)。
3. 打包時間約需 10 ~ 15 分鐘，請耐心等待。
4. 當圓圈變成 [綠色打勾 ✅] 時，點擊該工作的標題。
5. 進入詳細頁面後，滑到最下方的 "Artifacts" 區塊。
6. 點擊 "android-app" 下載壓縮檔。
7. 解壓縮後，裡面的 "app-release.apk" 就是您的手機安裝檔。

4. 手機安裝注意事項
-----------------------------------------
● 卸載舊版：若手機已裝有舊版，建議先卸載再裝新版 (卸載前請記得備份資料檔)。
● 安全警告：安裝時若跳出「不安全」或「來源不明」，請點擊「仍要安裝」。
● 檔案傳輸：可透過 LINE、USB 線或雲端硬碟將 APK 傳到手機。

5. 常見問題排除
-----------------------------------------
● 打包失敗 (紅燈)：通常是 GitHub Actions 裡的套件版本衝突。
  目前穩定配置：Flet 0.22.1 + Flutter 3.19.6。
● 手機閃退：若程式使用了手機不支援的套件 (如 pandas)，可能需要修改程式碼。
